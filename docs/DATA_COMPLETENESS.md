**必须分两组看**，否则会得出错误结论：

「DOM 残件」判定依据是字段集：只有 `id` `content` `ip_location` `like_count`
`user_info` `sub_comment_count` `pictures` `_is_reply`，缺 `note_id` /
`create_time` / `status` / `sub_comments` 等 SSR 独有字段。

**占位值的证据**（不是猜测）：

## 已知边界（非缺陷）

1. **每篇只保障 5 条一级评论**。匿名态 SSR 只内联首页评论，分页接口
   `comment/page` 返回 461（IP + 接口滑窗配额），翻页需登录态。
   现有量已满足 jev 打分与 Layer 2 标准差（≥3 条）的样本要求。
2. **DOM 残件的 135 行元数据是占位值**，但 `id` 与 `content` 是真实的。
   对 jev 打分无影响（`load_comment` 只用 `id`/`content`/`like_count`，
   而评论 `liked` 只用于展示）；对 `regression/features.py` 有影响，
   那里的 `ip_location` / `create_time` / `like_count` 特征会失真。
3. **零评论 ≠ 无数据**。`note.json` 完整，jev 走笔记维度照常打分。
4. **2 篇匿名不可见**：`6abc5bb8`（SSR 只返回 10KB 空壳、零评论）、
   `6a17c863`（同样空壳，现有 10 条全部来自登录态 DOM 快照）。
   已验证与配额无关（同一时刻其他帖正常返回），属笔记侧可见性限制。
